# Task Tracker

Персональный трекер задач с матрицей Эйзенхауэра, Kanban-доской, Pomodoro-таймером и рабочим пространством с заметками и секретами. Репозиторий содержит веб-версию и нативное приложение для Windows.

## Baseline

Baseline фиксирует исходное состояние репозитория для Software Engineering Assignment #05 до последующих изменений функциональности. Исходный код приложения уже реализует:

- создание и ведение задач, общих для разделов приложения;
- матрицу Эйзенхауэра и Kanban-доску;
- детали задачи с описанием, чек-листом и ссылками;
- Pomodoro-таймеры и уведомления;
- рабочее пространство для заметок и секретов;
- настройки темы в нативной версии.

Доступны две версии: одностраничная веб-версия без внешних зависимостей и WPF-приложение на .NET Framework 4.8. Baseline-коммит `baseline` служит точкой отсчёта для следующих изменений. В проекте пока нет автоматических тестов, линтера или проверки типов; результаты этих проверок не заявляются.

## Сборка и запуск

### Нативное приложение для Windows

Нужны Windows и .NET Framework 4.x с компилятором C# `csc.exe` (приложение нацелено на .NET Framework 4.8). Сторонние пакеты устанавливать не требуется. Из корня репозитория в PowerShell:

```powershell
Push-Location .\win32
try {
    .\build.cmd
    if ($LASTEXITCODE -ne 0) { throw "Сборка завершилась с кодом $LASTEXITCODE" }
    Start-Process .\bin\TaskTracker.exe
}
finally {
    Pop-Location
}
```

Только собрать приложение можно так:

```powershell
Set-Location .\win32
.\build.cmd
```

Собранный файл: `win32/bin/TaskTracker.exe`. Каталог сборки исключён из Git. Команда `build.cmd` сама проверяет наличие компилятора и возвращает ошибку, если он не найден или сборка не удалась.

### Веб-версия

Откройте `win32/index.html` в браузере. Либо запустите локальный сервер из корня репозитория:

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory win32
```

Затем откройте `http://127.0.0.1:8765/`. Для корректной работы Python должен быть доступен в `PATH`.

## Линтеры и автоматические тесты

На baseline в репозитории ещё не добавлены тесты, линтер, проверка типов или скрипты для их запуска. Поэтому команды проверки пока отсутствуют, и их результат не следует считать успешным или неуспешным.

Когда соответствующие инструменты и скрипты будут добавлены, предполагаемые команды из корня PowerShell:

```powershell
.\scripts\lint.ps1
.\scripts\test.ps1
```

Эти команды — целевой интерфейс для будущей настройки; файлов `scripts/lint.ps1` и `scripts/test.ps1` пока нет. После добавления инструментов README нужно обновить с фактическими командами и требованиями к окружению.

## Данные и безопасность

Веб-версия хранит данные в `localStorage` текущего браузера. Нативная версия хранит их в `%APPDATA%\TaskTracker\data.json`; каталог можно переопределить через `TASKTRACKER_DATA_DIR`. Значения секрета в обеих версиях сохраняются в открытом виде. Не используйте эту функцию для настоящих паролей, токенов или других чувствительных данных.

Подробности функций, управления и ограничений приведены в [README нативной версии](win32/README.md).
